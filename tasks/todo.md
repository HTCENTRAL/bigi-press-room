## ✅ 確定仕様（変更禁止）

### 前提
- 全ブランドが1スプシで1年運用
- プレスリース・工場貸出・店舗貸出で共用
- プレスメンバー以外の社員・店舗スタッフも閲覧
- 既存データの移行は不要（新規スプシ想定）

### 返却日の扱い
- K列「返却予定日」・V列「返却日（実績）」の2列構成を**現状維持**
- Sidebar の「返却予定日」ラベルも変更しない

### 品番マスタ登録方法
- シートに**手動で直接入力**（インポート機能なし）

### 掲載リストの生成単位
- **メインブランド × 年** で1タブ
  - 例: `L'EQUIPE_2025年_掲載リスト`
  - 同ブランド・同年の再生成 → 上書き
  - 同ブランド・別年 → 別タブ追加
- データのある月のみ表示（空月はスキップ）
- 1月〜12月を縦に展開し、各月に ①〜④ 種別セクション

### メインブランドとブランドの関係
- メインブランド（親）の下に子ブランドがぶら下がる構造
- 例: メインブランド = `L'EQUIPE`、子ブランド = その配下ブランド

### 伝票編集のアイテムCRUD
- **注意書きのみ**（実装しない）
- 「アイテムの追加→新規貸出登録、削除→返却処理をしてください」

### 貸出先マスタ
- お名前・電話番号の2項目のみ
- 新規登録時に自動upsert

## 📦 品番マスタコピペインポート機能

### 概要
「品番マスタコピペ先」タブにデータを貼り付け → ボタン1つで品番マスタに反映する機能。

### コピペ先 → 品番マスタ 列マッピング
| 品番マスタ列 | コピペ先列 | 処理 |
|---|---|---|
| A: メインブランド | C列（3） | そのまま |
| B: ブランド | — | **手入力のため保持**（UPSERTで上書きしない） |
| C: 品番 | F列（6） | そのまま（@形式） |
| D: カラー | K列（11） | そのまま（@形式） |
| E: カラー名 | L列（12） | そのまま |
| F: 単価(税込) | Q列（17） | × 1.1 → Math.floor（切り捨て） |
| G: アイテム名 | N列（14） | そのまま |

### 設計方針（追記のみ）
- ユニーク化キー: 品番 + カラーの組み合わせ
- 既存行（キー一致）: **完全スキップ**（既存レコードには一切触れない）
- 新規行（キー未存在）: 末尾に追記（ブランドは空欄）
- → 品番マスタへの手入力（ブランド含む全列）は常に安全
